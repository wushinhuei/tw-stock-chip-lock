# 資料蒐集完整性

| 資料 | 來源 | 自動完整性 | 處理方式 |
|---|---|---:|---|
| 上市公司清單 | TWSE OpenAPI | 可 | 每次更新核對 |
| 日 K、成交量 | TWSE MI_INDEX | 可 | 至少保存 120 個交易日 |
| 法人 | TWSE T86 | 可 | 未公布不得冒充當日 |
| 融資融券 | TWSE MI_MARGN | 可 | 計算餘額變化與券資比 |
| 月營收 | MOPS | 可 | 回補 36 月、去重並保留修訂雜湊 |
| 重大訊息與公司事件 | MOPS/TWSE OpenAPI | 可 | 供風險複核 |
| 千張大戶、股東人數 | TDCC | 部分 | 每週保存快照，至少三期才完整 |
| 券商分點與隔日沖 | 人工來源 | 不可 | 保存來源、日期與判讀 |
| 真實融資維持率 | 個別券商帳戶 | 不可 | 不蒐集、不顯示假精準數字 |

## 狀態語意

- `VERIFIED`：核心市場資料、TDCC 三期及個股連續 36 月營收完整。
- `PROVISIONAL`：核心市場資料完整，但 TDCC、營收或人工研究尚未補齊。
- `UNAVAILABLE`：價格、法人或資券缺漏、錯位或過期，不產生排行榜。

底層 manifest 另保留 `COMPLETE`、`PARTIAL`、`BLOCKED`、`STALE`，記錄來源、資料日期、下載時間、筆數、缺漏、警告與輸出 SHA-256。`PARTIAL` 可以發布暫定榜；`BLOCKED` 與 `STALE` 不可發布榜單。

歷史 MOPS 營收只供目前 36 月比較。沒有可靠發布時間的資料不回推過去榜單；人工分點與排名成效均只向前累積。因此整體不可宣稱 100% 自動或 100% 歷史完整。
