# 資料蒐集完整性

| 資料 | 來源 | 自動完整性 | 說明 |
|---|---|---:|---|
| 上市普通股清單 | TWSE OpenAPI | 可 | 每次更新重新核對 |
| 日 K 與成交量 | TWSE MI_INDEX | 可 | 保存日期與筆數 |
| 三大法人 | TWSE T86 | 可 | 未公布不得冒充當日資料 |
| 融資融券 | TWSE MI_MARGN | 可 | 可計算餘額變化及券資比 |
| 公司與重大訊息 | MOPS/TWSE OpenAPI | 可 | 只供風險複核 |
| 千張大戶、股東人數 | TDCC | 部分 | 歷史有限，需逐週累積 |
| 券商分點 | 人工來源 | 不可 | 保存來源、日期與判讀 |
| 真實融資維持率 | 個別券商帳戶 | 不可 | 本專案不蒐集、不推估為真值 |
| 盤中價量 | TWSE MIS | 當下可 | 透過 Worker；120 秒後失效 |

## 狀態

- `COMPLETE`：所有必要資料存在、日期一致且筆數合理，可以產生進場或加碼訊號。
- `PARTIAL`：只有非必要資料缺漏，只能顯示觀察結果。
- `BLOCKED`：價格、法人、融資融券或 TDCC 必要資料缺漏，禁止新風險。
- `STALE`：沿用過去資料，必須顯示原日期並禁止新風險。

每個輸出 manifest 都包含來源、資料日期、抓取時間、筆數、缺漏欄位、警告與 SHA-256。任何無法驗證的第三方數字不得補入官方欄位。
